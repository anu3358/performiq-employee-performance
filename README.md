# 📈 PerformIQ — Explainable Employee Performance Prediction

An AI app that predicts how an employee is likely to perform, **explains why**, suggests fair next steps,
and **checks itself for bias**. Built with Python, scikit-learn, XGBoost, SHAP and Streamlit.

> 🔗 **Live demo:** _add your Streamlit link here_

## ✨ Features
- 🎯 **Predictor** – live what-if sliders, probability chart, reasons for the result (SHAP) and suggested actions
- 📂 **Team analysis** – upload a CSV, score everyone, download results
- 🔍 **Model insights** – accuracy, F1, ROC-AUC, confusion matrix, model comparison, key factors
- ⚖️ **Fairness audit** – gender and age are never given to the model; they are only used to check for gaps
- 🧠 **How it works** – pipeline diagram and interview-style Q&A

## 🧱 How it is built
```
data (HR records) → clean & encode → compare 3 models → keep the best → explain with SHAP → fairness audit → Streamlit app
```
| Folder | What it holds |
|---|---|
| `app.py`, `pages/`, `piq/ui.py` | The screens (frontend) |
| `piq/` | Data, training, explanations, prediction engine (backend) |
| `data/` | Employee dataset (CSV) |
| `models/` | Saved model, scores and factor importance |
| `tests/` | Safety checks |
| `train.py` | One command to (re)train everything |

## 🚀 Run it on your computer
```bash
pip install -r requirements.txt
python train.py          # trains and saves the model
streamlit run app.py
```

## 📊 About the data
The bundled dataset is **synthetic** (generated by `piq/data.py`) so the project runs anywhere and
contains no real people's information. To use real data, place a CSV at `data/employees.csv` with the
columns listed in `piq/config.py` plus a `performance` column
(`Needs Improvement`, `Meets Expectations`, `Exceeds Expectations`), then run `python train.py`.

## ⚠️ Responsible use
Predictions support — never replace — a manager's judgement. Models learn from past data, so past
unfairness can leak in; keep checking the fairness page.
